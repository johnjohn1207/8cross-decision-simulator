# 8-Cross 手機競賽即時產銷決策模擬器

8-Cross Decision Simulator 是一套專為企業管理經營模擬競賽打造的高精度產銷與財務決策支援系統。系統完整內建模擬競賽的核心非線性約束模型、產能損耗、員工訓練三級晉升機制與動態損益校準邏輯，協助決策團隊在有限資源下推導出最佳生產、定價與資本配置。

---

## 核心演算模型與特色

### 1. 雙重產能瓶頸（TOC 產能約束）
模擬器依據生產作業現場實際限制，採用雙重瓶頸約束取極小值：
$$\text{有效產能} = \min(\text{工時換算產能}, \text{原料投產換算量} \times \text{良率係數})$$
* **工時產能**：依據各工段標準工時、人員配置與平均生產力換算。
* **投產產能**：原料投產換算之理論上限，乘以實際綜合良率 **0.738**（扣除製程耗損與瑕疵）。

### 2. 員工訓練與階級晉升機制
模型精確還原三級培訓體系與工資／熟練度曲線：
* **一級員工（初階）**：新進人員基礎生產力與底薪基準。
* **二級員工（中階）**：經過 1 期培訓後升級，熟練度提高，薪資對應調整。
* **三級員工（高階）**：經過 2 期培訓後升級，具備最高人均產能與抗損耗率。
* 總工時採加權移動平均計算，避免過度樂觀估算新進員工產能。

### 3. 動態財報校準與損益模擬
* **歷史資料比對**：內建 M1 至 M10 歷史損益與資產負債數據，與官方報表差異小於 0.2%。
* **現金流量與舉債成本模擬**：即時試算短期借款、長期貸款之利息支出，評估加權平均資金成本（WACC）與稅盾效益。
* **敏感度分析**：即時反應原物料採購量、行銷推廣費用、研發支出對營業利益率與每股盈餘（EPS）之影響。

## 本地與線上執行說明

本系統為單一純前端 HTML5 / JavaScript 應用程式，無須安裝額外依賴套件或後端伺服器：
1. **GitHub Pages 託管**：直接造訪本專案之 GitHub Pages 網址即可進行線上試算。
2. **本機獨立執行**：將本儲存庫下載至本機後，直接以任一現代瀏覽器（Chrome、Edge、Safari、Firefox）開啟 `index.html` 即可完整離線運作。
